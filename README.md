# IDS.FillParameters

# IDS Parameter Filler для Revit

Плагин для автоматического заполнения параметров элементов Revit с целью прохождения 100% проверки по **Information Delivery Specification (IDS)**. Плагин работает в режиме "добивки": исправляет только проблемные параметры, указанные в отчете IfcTester, не трогая корректно заполненные данные.

## 🚀 Ключевые возможности

- **Парсинг отчетов IfcTester:** Читает `.ods` файлы (ZIP-архивы с `content.xml`).
- **Умное создание параметров:** Если параметр отсутствует в проекте, плагин автоматически создает его как общий (Shared Parameter) и привязывает к категории элемента.
- **Авто-привязка категорий:** Если параметр уже есть в проекте, но не привязан к текущей категории элемента, плагин обновляет привязку (`ReInsert`).
- **Генерация валидных значений:** Автоматически подставляет минимально допустимые значения на основе ограничений IDS (Enumeration, Regex Pattern, MinLength) или типа данных (Text, Real, Integer, Boolean).
- **Кросс-версионность:** Стабильная работа в Revit 2022–2026+ благодаря использованию рефлексии для обхода изменений API (`ElementId`, `ForgeTypeId`/`SpecTypeId`).
- **Детальное логирование:** Все действия, предупреждения и ошибки записываются в лог-файл.

## 📋 Требования

- Autodesk Revit 2022 или новее
- .NET Framework 4.8 / .NET 8 (в зависимости от версии Revit)
- Библиотека логирования `RevitLogger` (должна быть подключена к проекту)

## 🛠️ Как использовать

1. Запустите команду **"Заполнить IDS по отчету"** на вкладке **ISTools**.
2. В открывшемся диалоге выберите **ODS-файл** с отчетом IfcTester.
3. Выберите **TXT-файл** с правилами маппинга (стандартный файл мэппинга для ifc).
4. Дождитесь завершения обработки. Итоговое окно покажет статистику: сколько параметров заполнено, пропущено и список незамапленных свойств.
